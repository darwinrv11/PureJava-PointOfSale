# PureJava Point of Sale (POS) System 🛒

A robust desktop Point of Sale (POS) application built entirely in Java using NetBeans, featuring an Object-Oriented Programming (OOP) architecture, a native graphical user interface, and a MySQL database backend designed for retail and small business management.

---

##  Key Features

* **Object-Oriented Architecture:** Designed with modular classes, encapsulation, inheritance, and a clean separation of business logic and data access layers.
* **User Authentication & Access Control:** Secure login workflow handling user sessions and operations.
* **Inventory & Product Management:** Real-time stock tracking, product categorization, and pricing management.
* **Sales & Transactions:** Fast checkout workflow supporting item registration, total calculations, and transaction records.
* **MySQL Database Integration:** Reliable data persistence connected via JDBC to a local MySQL server (port 3066).

---

## 🛠️ Technologies Used

* **Language:** Java (JDK 17+)
* **IDE:** NetBeans
* **Paradigm:** Object-Oriented Programming (OOP)
* **Database:** MySQL (Local port 3066)
* **Version Control:** Git & GitHub
